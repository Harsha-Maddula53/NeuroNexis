# AI Disclosure Requirements (Trust & Safety)

## Core Principle
NeuroNexis operates on a fundamental principle of transparency: **Humans must always know when they are talking to an AI.** Failing to disclose AI identity breaks trust, violates platform terms, and introduces severe Trust & Safety risks.

## Technical Requirements

1. **Database Level (Permanent Record)**
   - All AI-generated messages must have `isAi: true` set in the database.
   - **Crucial Limitation:** The raw message `content` must remain exactly as generated by the AI. Do NOT bake `(AI Representation)` or similar prefixes into the database string itself. This corrupts future LLM context, bloats the database, and complicates output moderation. Disclosure is strictly a rendering and export concern driven off the `isAi` boolean.

2. **UI Level (Frontend)**
   - Any message where `isAi` is true must display a prominent, non-dismissible badge indicating "AI Representation".
   - The UI currently implements this via `<Badge variant="ai">AI Representation</Badge>` directly above the chat bubble.
   - The AI's confidence level (High/Medium/Low) should also be displayed alongside the badge to set appropriate expectations for accuracy.

3. **Backend Logic**
   - No AI message should ever be sent via the standard `/api/chat` route pretending to be a human. AI responses are generated and saved strictly through `/api/ai/respond`.

## Enforcement
- Code reviews must verify that `isAi: true` is properly set, and that no code artificially injects disclosure prefixes into raw DB strings.
- `Llama Guard` moderation checks all generated content.
- Users have the ability to report and block AI representations that behave inappropriately.

## Known Limitations (Deferred to Post-MVP)
- **Admin Report Pipeline:** Currently, when a user clicks "Report," a record is created in the `Report` table. However, there is no Admin UI or human review queue built to actually read and adjudicate these reports. This is a known structural gap in Phase 2 Trust & Safety that must be addressed before mass public scale.
